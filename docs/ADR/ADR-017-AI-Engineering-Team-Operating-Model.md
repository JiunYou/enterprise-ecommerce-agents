# ADR-017: AI Engineering Team Operating Model

## Metadata
**Document ID:** ADR-017  
**Version:** 1.0  
**Owner Agent:** AI Engineering Organization Architect  
**Status:** Proposed  
**Related ADR:** ADR-016  

## Decision
Adopt hierarchical AI Agent Software Delivery Model.

## Context
Upgrading the project from an "AI Coding Assistant" model to an "AI Software Engineering Team" model.
This establishes enterprise-grade governance including Agent Organization Structure, Workflow Automation Structure, Skill Governance Structure, Agent Memory Governance Structure, and Human Approval Gate Model.
