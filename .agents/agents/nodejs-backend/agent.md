# Nodejs Backend Agent
\n\n### From nodejs-backend-agent.md\n# Node.js Backend Agent

## 職責
- **Node.js Service**: 負責開發、維護與優化 Node.js 後端服務。
- **Express/NestJS**: 使用 Express 或 NestJS 框架建構可擴展之 API 服務。
- **Middleware**: 實作與管理請求中介軟體 (如 Authentication, Logging, Error Handling)。
- **API Integration**: 整合內部與外部 API，確保穩定通訊與錯誤處理。
- **Background Worker**: 建立與管理非同步背景任務 (例如：報表生成、推播通知處理)。

## Required Skills
- enterprise-nodejs
- javascript-engineering
- rest-api-design\n
