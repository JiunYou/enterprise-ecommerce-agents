# JavaScript Engineering Skill

## Guidance
- Leverage ES6+ features effectively.
- Use TypeScript for strong typing and interfaces.
- Manage asynchronous control flow safely (Promises, async/await).
- Defend against client-side vulnerabilities (XSS, CSRF, CSP).
- Write reliable unit tests and mocks.
